# F-002

## Scam Call Guardian

**Priority:** P0

**Status:** Planned

### Objective

Reduce successful phone-based financial scams.

### Description

Displays a safety overlay during unknown calls and performs post-call scam analysis.

### Features

- Incoming Call Overlay
- Safety Reminder
- Post-call Questionnaire
- AI Scam Analysis
- Suggested Actions

### Output

- Safe
- Suspicious
- High Risk

### Dependencies

- Phone State Listener
- AI Risk Engine
- Alert Manager

### Success Criteria

- Safety reminder displayed during unknown calls.
- High-risk calls correctly identified.
